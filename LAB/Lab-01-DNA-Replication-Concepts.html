Lab 01: DNA Structure and Replication Modeling

Experiment Title

DNA Structure Recognition and Replication Fork Modeling

Learning Objectives

  1. Identify key structural features of the DNA double helix relevant to replication
  2. Construct and interpret a model of the replication fork
  3. Demonstrate understanding of leading and lagging strand synthesis
  4. Identify the roles of major replication proteins

Background Theory

DNA replication requires understanding of:

  • Antiparallel strand orientation (5'→3' and 3'→5')
  • Complementary base pairing (A-T, G-C)
  • Semiconservative replication
  • Replication fork structure (Y-shaped)
  • Okazaki fragments on the lagging strand

Materials

For Modeling Exercise

Material Quantity Notes
Colored paper strips (4 colors) 8 per group Represent nucleotides (A, T, G, C)
Scissors 1 per group
Tape or glue As needed
Markers/pens As needed
Printed replication fork diagram 1 per group Reference

Equipment

  • None required (paper-based modeling)

Safety Considerations

  • Standard classroom safety only
  • Handle scissors carefully

Experimental Principle

The replication fork is a Y-shaped structure where:

  • Helicase unwinds the double helix
  • Leading strand is synthesized continuously toward the fork
  • Lagging strand is synthesized discontinuously away from the fork as Okazaki fragments
  • Each Okazaki fragment requires its own RNA primer

Step-by-Step Procedure

Part A: DNA Structure Recognition (15 minutes)

  1. Using colored paper strips, create a 20-base-pair double-stranded DNA molecule

    • Use 4 colors for A, T, G, C
    • Ensure complementary base pairing
    • Write 5' and 3' labels on each strand
    • Ensure strands are antiparallel

  2. Answer the following:

    • What is the sequence of the top strand? 5'→3'
    • What is the sequence of the bottom strand? 5'→3'
    • How many hydrogen bonds between A-T? Between G-C?
    • Which end would DNA polymerase read from?

Part B: Replication Fork Construction (20 minutes)

  1. Cut your DNA model at the middle to represent helicase unwinding
  2. Separate the strands to create a Y-shaped fork
  3. Label the following on your model:
    • 5' and 3' ends of each strand
    • Template strand for leading strand
    • Template strand for lagging strand
    • Direction of fork movement

Part C: Leading and Lagging Strand Synthesis (25 minutes)

  1. Using new colored strips, synthesize the leading strand:

    • Identify which template strand to use
    • Build the new strand 5'→3' toward the fork
    • Only one primer needed (use a different color for RNA primer)

  2. Synthesize Okazaki fragments on the lagging strand:

    • Use a different color for each fragment
    • Each fragment should have an RNA primer (different color) + DNA
    • Build fragments 5'→3' but away from the fork
    • Make 3-4 fragments

  3. Label:

    • Leading strand (continuous)
    • Lagging strand (discontinuous)
    • Okazaki fragments
    • RNA primers
    • Direction of synthesis on each strand

Expected Observations

Observation Expected Result
Leading strand Single continuous strand, one primer at start
Lagging strand Multiple fragments, each with primer
Fragment orientation Each Okazaki fragment 5'→3'
Overall lagging direction Opposite to fork movement
Complementarity New strands complementary to templates

Results Table

Feature Leading Strand Lagging Strand
Synthesis direction 5'→3' (toward fork) 5'→3' (away from fork)
Continuity Continuous Discontinuous
Number of primers 1 Multiple (one per fragment)
Okazaki fragments None Yes (3-4 in model)
Template strand 3'→5' (toward fork) 5'→3' (toward fork)

Calculations

Fork Speed Calculation

If the replication fork moves at 1,000 nt/second in E. coli:

Question: How long would it take to replicate a 2,000 bp Okazaki fragment?

Answer:

  • Speed = 1,000 nt/second
  • Okazaki fragment = 2,000 nt
  • Time = 2,000 / 1,000 = 2 seconds

Question: If E. coli genome is 4.6 × 10⁶ bp and replication is bidirectional from one origin, how many nucleotides does each fork copy?

Answer:

  • Each fork copies half = 2.3 × 10⁶ nt
  • Time = 2.3 × 10⁶ / 1,000 = 2,300 seconds ≈ 38 minutes

Interpretation

  1. Why can't both strands be synthesized continuously?
  2. What would happen if Okazaki fragments were not joined?
  3. How does the antiparallel nature of DNA necessitate the lagging strand mechanism?

Troubleshooting

Problem Possible Cause Solution
Fragments not oriented correctly Confusion about 5'→3' direction Re-check polarity of template strand
Leading strand has multiple primers Confused leading/lagging Leading strand only needs one primer
Fragments too large Not following template Ensure complementary base pairing

Post-Lab Questions

  1. In your model, what protein would remove the RNA primers? (See Module 03)
  2. If a mutation prevented Okazaki fragment ligation, what would be the consequence?
  3. Why is it important that DNA polymerase only synthesizes in the 5'→3' direction?
  4. Draw a diagram of your completed replication fork model.

Viva Questions

  1. What is the direction of DNA synthesis? Why?
  2. Explain why the lagging strand is called "lagging."
  3. What would happen if helicase worked in only one direction?
  4. How many primers are needed per replication fork?
  5. What is the role of the sliding clamp?

Expected Answers

  1. 5'→3' direction — DNA polymerase can only add nucleotides to the free 3'-OH group.
  2. Lagging strand is synthesized in the direction opposite to fork movement, making it "lag behind" the leading strand in overall synthesis.
  3. If helicase worked unidirectionally — only one fork would form, doubling replication time.
  4. Two primers per fork — one for leading strand, one initially for lagging strand (plus new primers for each Okazaki fragment).
  5. Sliding clamp increases polymerase processivity by tethering it to the DNA template.

Instructor Notes

  • Common student error: confusing template strand polarity with synthesis direction
  • Allow time for students to physically build the model before abstracting
  • Use this lab to set up the conceptual foundation for all subsequent labs
  • This is a modeling/discussion exercise, not a wet-lab experiment
  • Connect to Module 01 and Module 02 lecture content
