## Comprehensive Comparison Tables

### 1. Genome and Chromosome Structure

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Genome size | 4.6 × 10⁶ bp | 3.2 × 10⁹ bp |
| Chromosome number | 1 (usually circular) | 46 (linear) |
| Chromosome structure | Circular dsDNA | Linear dsDNA + telomeres |
| Supercoiling | Negative supercoiling | Nucleosome-based packaging |
| Organization | Nucleoid | Nucleus with chromatin |
| Associated proteins | HU, H-NS, IHF, FIS | Histones (H2A, H2B, H3, H4), H1 |
| Packaging ratio | ~1000:1 | ~10,000:1 |

### 2. Origins of Replication

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Number of origins | 1 (oriC) | 30,000–50,000 |
| Origin size | 245 bp | ~100-400 bp (variable) |
| Sequence specificity | High (DnaA boxes, 13-mers) | Low (chromatin-dependent) |
| Initiator protein | DnaA | ORC (Orc1-6) |
| Origin regulation | DnaA-ATP/ADP ratio | CDK/DDK, geminin |
| Licensing system | None (single origin) | Pre-RC (ORC → Cdc6 → Cdt1 → MCM) |
| Firing control | Once per cell cycle | Once per cell cycle (licensing) |

### 3. Replication Initiation

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Initiator | DnaA-ATP | ORC complex |
| Helicase loader | DnaC | Cdc6 + Cdt1 |
| Replicative helicase | DnaB (3'→5') | CMG (Cdc45-MCM2-7-GINS) (5'→3') |
| Helicase orientation | Encircles lagging strand template | Encircles lagging strand template |
| Helicase loading | At origin (single complex) | At origin (double hexamer) |
| Activation | DnaA-dependent | CDK + DDK dependent |
| Bidirectional | Yes (2 forks) | Yes (2 forks per origin) |

### 4. Elongation

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Replicative polymerase | Pol III holoenzyme | Pol ε (leading), Pol δ (lagging) |
| Primase | DnaG | Pol α/primase |
| Sliding clamp | β₂ (homodimer) | PCNA (homotrimer) |
| Clamp loader | γ complex (5 subunits) | RFC (5 subunits) |
| SSB protein | SSB | RPA (RPA1-3) |
| Processivity factor | β clamp | PCNA |
| Fork speed | ~1,000 nt/s | ~50 nt/s |
| Replication time | ~40 min | ~6-8 hours (S phase) |
| Total nucleotides/fork | ~2.3 × 10⁶ | Variable (depends on inter-origin distance) |

### 5. Okazaki Fragments

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Size | 1,000–2,000 nt | 100–200 nt |
| RNA primer length | ~10–12 nt | ~8–12 nt |
| Primer removal | Pol I (5'→3' exonuclease) | RNase H2 + FEN1 |
| Gap filling | Pol I | Pol δ |
| Ligation | DNA ligase (NAD⁺) | DNA ligase I (ATP) |
| Total fragments/fork | ~2,300 | ~15,000 |

### 6. Proofreading and Repair

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Proofreading enzyme | ε subunit of Pol III | 3'→5' exonuclease of Pol ε/δ |
| Mismatch repair | MutS/MutL/MutH | MSH2-6/MLH1-PMS2 |
| Strand discrimination | Dam methylation (GATC) | Strand nicks (PCNA-dependent) |
| BER | Multiple glycosylases | Pol β-dependent pathway |
| NER | UvrABC system | XPC/TFIIH/XPB/XPD |
| Final error rate | ~10⁻⁹–10⁻¹⁰ | ~10⁻⁹–10⁻¹⁰ |

### 7. Topoisomerases

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Type II (ahead of fork) | DNA Gyrase | Topoisomerase IIα |
| Type I | Topoisomerase I | Topoisomerase I |
| Decatenation | Topoisomerase IV | Topoisomerase IIα |
| Unique feature | Gyrase introduces negative supercoils | No gyrase in eukaryotes |
| Drug target | Fluoroquinolones | Etoposide (Topo II), Camptothecin (Topo I) |

### 8. Termination

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Termination site | Defined (Ter region) | Not defined (forks meet anywhere) |
| Termination system | Tus/Ter (polar trap) | None |
| Fork convergence | At Ter region | Wherever forks meet |
| Post-termination | Decatenation (Topo IV) | CMG disassembly (p97/Cdc48) |
| Catenane problem | Yes (circular chromosomes) | Minimal (linear chromosomes) |
| Chromosome segregation | FtsK, MukBEF | Cohesin, condensin, Smc |

### 9. Telomeres

| Feature | Prokaryotes | Eukaryotes |
|---------|-------------|------------|
| Telomere presence | No (circular chromosome) | Yes (linear chromosomes) |
| Telomere sequence | N/A | TTAGGG (humans) |
| Telomerase | No | Yes (TERT + TERC) |
| End-protection | N/A | Shelterin complex |
| End-replication problem | No (circular) | Yes (linear) |

### 10. Cell-Cycle Regulation

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Cell cycle | Overlapping (no discrete phases) | Discrete (G1, S, G2, M) |
| Division control | FtsZ ring, Min system | Cyclin-CDK oscillations |
| Checkpoint | SOS response (minor) | ATR-CHK1, ATM-CHK2 (extensive) |
| Re-replication prevention | Overlapping initiation (no licensing) | Licensing system (CDK/Geminin) |
| Growth rate control | Growth rate → initiation frequency | Developmental → S-phase timing |

### 11. Chromatin/Chromosome Dynamics

| Feature | Prokaryotes (E. coli) | Eukaryotes (Human) |
|---------|----------------------|-------------------|
| Chromatin structure | Nucleoid (HU, H-NS) | Nucleosomes + higher-order |
| Nucleosome disassembly | N/A | FACT complex, histone chaperones |
| Nucleosome reassembly | N/A | CAF-1, ASF1 |
| Histone recycling | N/A | MCM2, FACT |
| Epigenetic inheritance | Limited (DNA methylation) | Extensive (histone marks, DNA methylation) |
| Replication timing | Not applicable | Early vs. late S phase |

## Conservation of Replication Mechanisms

### What is Conserved?

Despite billions of years of evolution, certain features are remarkably conserved:

1. **Semiconservative replication** — universal
2. **5'→3' synthesis** — universal
3. **Need for primers** — universal
4. **Sliding clamp** — ring-shaped processivity factor (prokaryotic β₂ → eukaryotic PCNA)
5. **Clamp loader** — AAA+ ATPase machine
6. **3'→5' proofreading exonuclease** — conserved in replicative polymerases
7. **Okazaki fragments** — discontinuous lagging strand synthesis
8. **SSB/RPA** — single-strand binding proteins
9. **Helicase** — ring-shaped hexameric motor
10. **Topoisomerase** — relieve torsional stress

### What Differs?

| Feature | Reason for Difference |
|---------|----------------------|
| Multiple origins | Larger genome needs faster replication |
| Licensing system | Prevents re-replication of large genome |
| Chromatin | Packaging of large genome in nucleus |
| Telomeres | Linear chromosomes need end protection |
| Slower fork speed | Nucleosome obstacles, more complex regulation |
| More polymerases | Specialized functions, chromatin context |
| Complex checkpoints | Larger genome, more at stake |

## Archaeal Replication — An Evolutionary Bridge

Archaea share features with both bacteria and eukaryotes:

| Feature | Bacteria | Archaea | Eukaryotes |
|---------|----------|---------|------------|
| Genome | Circular | Circular (usually) | Linear |
| Origins | oriC (single) | Multiple (ORC-like) | Multiple (ORC) |
| Initiator | DnaA | Orc1/Cdc6 | ORC complex |
| Helicase | DnaB (3'→5') | MCM (5'→3') | CMG (5'→3') |
| Clamp | β₂ (dimer) | PCNA (trimer) | PCNA (trimer) |
| Clamp loader | γ complex | RFC | RFC |
| Polymerase | Pol III | PolB/PolD | Pol α/δ/ε |
| Primase | DnaG | PriS/PriL (eukaryotic-type) | Pol α/primase |
| MMR | MutS/MutL/MutH | MSH homologs | MSH2-6/MLH1-PMS2 |

> Archaeal replication machinery is **eukaryotic-like**, reflecting their shared evolutionary ancestry. This is one of the strongest arguments for the three-domain classification of life.
